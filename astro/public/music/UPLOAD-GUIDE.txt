# 音樂上傳指南

## 使用 Git LFS 上傳大檔案

### 1. 初始化 Git LFS（如果還沒有）
```bash
git lfs install
```

### 2. 將檔案放入對應資料夾

**MP3 音樂檔案：** 放入 `astro/public/music/`
- 例如：`astro/public/music/mysong.mp3`

**LRC 歌詞檔案：** 放入 `astro/public/music/lyrics/`
- 檔案名稱需與歌曲 ID 對應
- 例如：`astro/public/music/lyrics/mysong.lrc`

### 3. 在 music-list.js 中註冊歌曲
```javascript
const DEFAULT_PLAYLIST = [
    {
        id: 'mysong',
        title: '我的歌曲名稱',
        artist: '藝術家',
        album: '專輯名稱',
        url: '/music/mysong.mp3',  // 對應 public/music/ 裡的檔案
        cover: '',  // 可留空或放專輯圖片 URL
        duration: 240,  // 秒數
        hasLyrics: true
    }
];
```

### 4. 提交並推送
```bash
git add astro/public/music/
git add astro/public/music/lyrics/
git add astro/src/scripts/music-list.js
git commit -m "新增歌曲：mysong"
git push
```

### 5. 觸發 Vercel 重新部署
推送完成後，Vercel 會自動偵測並部署。

## 支援的檔案格式
- MP3 (.mp3) - 音樂
- WAV (.wav) - 音樂
- FLAC (.flac) - 無損音樂
- OGG (.ogg) - 音樂
- M4A (.m4a) - 音樂
- AAC (.aac) - 音樂
- LRC (.lrc) - 動態歌詞
- TXT (.txt) - 純文字歌詞

## Git LFS 配額
- 預設 2GB 免費儲存空間
- 每月 1GB  bandwidth

## 範例 LRC 歌詞格式
```
[ti:我的歌曲]
[ar:藝術家]
[al:專輯]
