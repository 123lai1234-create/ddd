# LRC 動態歌詞格式說明

## 檔案格式
使用 .lrc 副檔名，支援時間軸歌詞同步。

## 格式範例
```
[ti:歌曲標題]
[ar:藝術家]
[al:專輯名稱]
[00:00.00] ♪ 前奏 ♪
[00:12.34] 第一段歌詞
[00:15.67] 第二段歌詞
[00:20.00] 第三段歌詞
```

## 時間戳格式
- `[分:秒.百分秒]` 或 `[分:秒]`
- 例如：`[01:23.45]` = 1分鐘23.45秒

## 檔案命名
- 檔案名稱需與歌曲 ID 對應
- 例如：`song1.lrc` 對應 `id: 'song1'` 的歌曲

## 與 TXT 的區別
- TXT：簡單逐行顯示，自動平分時間
- LRC：精確時間軸對應，隨音樂動態同步

## 自動偵測
系統會自動偵測是否為 LRC 格式：
- 有時間戳 → 使用 LRC 精確同步
- 無時間戳 → 使用 TXT 平均分配時間
