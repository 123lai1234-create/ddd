A0006 使用者權限管理 教育訓練

📋 系統概述

A0006 模組提供使用者帳號與角色權限的 CRUD 管理功能，支援：

  • 查詢現有使用者及其角色
  • 新增使用者（含密碼加密儲存）
  • 修改使用者資料及角色
  • 刪除使用者
  • 取得角色選項清單

🔌 API 端點

1. 取得角色選項

GET /api/A0006/options

說明：取得所有可用的角色選項（含角色代碼與描述）

Response:
{
  "roles": [
    { "roleCode": "ADMIN", "roleDesc": "系統管理者" },
    { "roleCode": "USER", "roleDesc": "一般使用者" }
  ]
}

2. 查詢使用者角色

GET /api/A0006/userRole?userId=&isEnabled=

參數：

  • userId - 使用者帳號（模糊查詢）
  • isEnabled - 啟用狀態（0: 停用, 1: 啟用）

3. 新增使用者

POST /api/A0006/userRole

必填欄位：userId, userType, userPwd, userEmail, userIsEnabled

Request:
{
  "userId": "test001",
  "userName": "測試使用者",
  "userType": 1,
  "userPwd": "Pass123!",
  "userEmail": "test@example.com",
  "userNote": "測試帳號",
  "userIsEnabled": 1,
  "roles": [
    { "roleCode": "USER", "roleNote": "" }
  ]
}

4. 修改使用者

PATCH /api/A0006/userRole

必填欄位：userId, userType, userEmail, userIsEnabled

5. 刪除使用者

DELETE /api/A0006/userRole 
Request:
{ "userId": "test001" }

⚠️ 注意事項

  • 密碼需符合 PasswordPolicy（長度、複雜度）
  • 密碼會使用 AES-256-GCM 加密後儲存
  • 刪除使用者會一併刪除其角色關聯
  • operator（操作人員）待從 Security Context 取得
