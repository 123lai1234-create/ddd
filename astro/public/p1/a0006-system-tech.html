① 元件關係圖（Component Relationship）

由左至右呈現分層架構：外部 → API → Service → DTO / Util → Repository → Model → DB。

線條： 主流程（呼叫） 資料流 依賴 / 工具 節點： API / Controller Service DTO Util Repository Model Database

📌 閱讀順序： 由左至右：外部 → API Controller → Service → 視需要呼叫 Utils（加密/密碼/編碼）或透過 Repository 存取 Model 與 DB。
圖例： 紅色粗箭頭 = 主要呼叫流程；細實線 = 資料流；虛線 = 物件或工具依賴。
