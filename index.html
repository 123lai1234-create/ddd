核心演算法

數學基礎與原理

每個模組對應大分子 AI 演算法研究的一項關鍵能力指標。

ESM-2：預訓練蛋白質語言模型

ESM-2 是一個 以 UniRef 中 2.5 億層蛋白質序列通過 遮罩語言模型（MLM）訓練的 Transformer。预訓練期間，15% 的 tokens 被遮罩，模型學習預測它們，此過程迫使模型捕捉演化共變、二級結構訊號與接觸資訊。

我們使用 facebook/esm2_t6_8M_UR50D模型（8M 參數）作為 凍結特徵擷取器。對所有殘基酸 tokens 做遮罩平均池化，經永產生一個固定 320-D 向量不管序列長度為何。

  • 嵌入步驟不需標註資料（零樣本遷移學習）
  • 透過自注意力捕捉長程依賴關係
  • 更大變體（650M、3B）對下游任務性能䑟呈線性提升
  • 遮罩平均池化忽略 padding tokens，支援變長序列
平均池化數學公式
輸入：長度為 L 的序列
ht∈ ℝ320=第 t 位置的 Transformer 隱藏狀態
mt∈ { 0, 1 } =注意力遮罩

z=Σ(mt · ht) / Σ mt

MLM 預訓練目標函數：
LMLM=−Σ log P(xt | x\t; θ)
程式實作Python 
withtorch.no_grad(): out=model(input_ids, attention_mask=mask) h=out.last_hidden_state # (B, L, 320)m=mask.unsqueeze(-1).float() z=(h * m).sum(1) / m.sum(1) # (B, 320)

貝葉斯最佳化：樣本高效的適應性搜尋

濕實驗室檢測費用是昂貴的——我們無法每序列全評估。貝葉斯最佳化將適應性函數視為未知 黑盒子，利用迄今為止的評估結果建立機率性高斯過程（GP）代理模型。

每一步，指標函數決定 接下來評估序列，平衡 利用（预測較高的區域）與 探索（不確定性較高的區域）。

  • GP 在序列空間任意點提供校準不確定性估計
  • qLogEI=對數空間期望改善，數學穩定（BoTorch 預設）
  • PCA 將 320-D 降至 8-D，保持 GP 協方差矩陣良好條件數
  • BO 完成後，逆 PCA 將建議潛在點映射回嵌入向量空間
指標函數數學公式
GP 後驗分布： f(x)~GP(μ(x), k(x, x'))

αLogEI(x)=log E[max(f(x) − f*, 0)]

解析式：
EI(x)=(μ(x)−f*) Φ(Z) + σ(x) φ(Z)
Z=(μ(x) − f*) / σ(x)

GP 核函數（Matérn-5/2）：
k(r)=(1 + √5r/l + 5r²/3l²) exp(−√5r/l)
程式實作Python 
# PCA 降維 → GP 擬合 → LogEI 指標 → 最佳化 X_pca=pca.transform(X_scaled) gp=SingleTaskGP(X_t, y_t) ei=qLogExpectedImprovement(gp, best_f) X_next, _=optimize_acqf(ei, bounds, ...) # 逆 PCA → oracle 查詢 → 更新 GP

ProteinMPNN：結構條件式序列設計

ProteinMPNN 在給定 蛋白質骨架（Cα 坐標）的前提下設計氺基酸序列。它將蛋白質建模為圖結構，每個殘基酸為節點，邊連接 3D 空間中的 k 個最近鄰。

多輪 訊息傳遞讓每個節點能聚合局部結構鄰域的資訊，再預測該位置的最佳氺基酸。

  • 邊特徵（19-D）：相對距離、二面角編碼
  • 節點特徵（16-D）：正弦二面角嵌入
  • k-NN 上限為 N−1，确保短序列安全處理
  • 每殘基酸用交叉熵訓練；推斷時對機率分布採樣
訊息傳遞數學公式
圖 G=(V, E)，V=歘基酸，E=Cα 上k-NN 邊

訊息： mvu=φ(hv(l), hu(l), evu)

hv(l+1)=LN(hv(l) + ReLU(WO · Σu∈N(v) mvu))

目標： LCE=−Σv log P(av | G; θ)

φ(hv, hu, e)=W1hv + W2hu + W3e
程式實作Python 
# scatter-add 訊息傳遞 msg=self.edge_mlp(torch.cat([h[src], h[dst], edge_attr], dim=-1)) agg=scatter_add(msg, dst, dim=0, dim_size=N) h=self.ln(h + F.relu(self.W_O(agg)))

REINFORCE：策略梯度式序列生成

我們將蛋白質設計建模為 順序決策問題。LSTM 策略網路每次自回歸地生成一個氺基酸 token，條件为前序生成結果。

REINFORCE 演算法更新策略以更大化期望獎勵（適應性）。我們使用 多目標獎勵，結合測預穩定性、疏水性與帶電荷比例。

  • 採樣在 torch.no_grad() 下執行以提升效率
  • 用 teacher-forcing 重新計算 log 機率，穩定梯度图
  • 平均獎勵基線減少變異性
  • 多目標：R=0.6·穩定性 + 0.3·疏水性 + 0.1·帶電荷比
策略梯度數學公式
策略： πθ(at | st)=LSTM(tokent-1, ht-1)

回報： Gt=Σt'≥t γt' -t rt'

∇θJ(θ)=Eπ[∇θ log πθ(at|st) · (Gt − b)]

獎勵： R=ws·fstab + wh·fhydro + wc·fcharged
程式實作Python 
# teacher-forcing log 機率重新計算 logits=policy(input_tokens) # 含梯度 log_p=F.log_softmax(logits, dim=-1) log_p=log_p.gather(-1, sampled[:, 1:].unsqueeze(-1)) loss=−(log_p.squeeze() * R_baseline).mean()

面試準備

預期面試問答

面試官最可能提問的核心技術問題，點擊每項展開詳細答案。

為什麼用 ESM-2 而不是 one-hot encoding 或 BLOSUM？
One-hot 把每個氺基酸獨立處理，忽略了決定蛋白質功能的替換偈向性與演化脈絡。BLOSUM 從比對中捕捉成對替換頻率，但它是固定的20×20 矩陣——無法表示具體序列中的歘基酸互作用。

ESM-2 學習上下文相依賦表示：歘基酸 L 的嵌入向量取決於自注意力處理整條序列，捕捉長程共演化限制。它也將預訓練腫隱式學到的結構知識轉移過來。實階上，ESM-2 嵌入在小資料情境下的適應性預測 (精確率) 比 one-hot 提升 15–30%。
為什麼在做 GP 之前要先做 PCA？
320-D 的 GP 需要計算一個含 320-D 核函數的 N×N 協方差矩陣。高維度下：1) 維度詛咒——距離指標失效，因為所有成對距離集中於相同値。2) 病態條件數——協方差矩陣 K 趨近奇異，Cholesky 分解（GP 推斷必須）在數學上失敗。

PCA 降至 8-D 保留 81.9% 嵌入變異量，同時使 GP 良好條件化。8 個主成分也對應訓練集中序列變化最有意義的軸。其他方案有 deep kernel（Deep GP 或 DKL），同時學習神經網路嵌入和 GP——這是對目下一步生產部署的自然影長。
REINFORCE vs PPO — 什麼時候該升級？
REINFORCE是無偏差但 高變異性的梯度估計器——作為原型相當好用，但訓練很喵囉。每阡回報直接用於更新策略，當獎勵稀疏或喵囉時（如蛋白質適應性）導致大梯度步進。

PPO（Proximal Policy Optimisation）切割策略比率以防止破壞性大更新，使用價値函數基線降低變異性，并能對同一批次資料多次訓練。對於蛋白質序列設計（長序列》高價車 Oracle），PPO 通常在少 5–10倍 Oracle 呼叫次數下收斂。

在實際生產中我會升級到 PPO，並進一步考慮 GRPO（DeepSeek-R1 所用）——無需獨立價値網路，在同一批次採樣序列中計算優勢，直接適用於我們的序列生成場景。
這個 pipeline 如何接到真實濕實驗室？
這個系統實現一套 貝葉斯主動學習迴圈：

1. 第 0 輪：以小型庫存出發（例：組合設計的 24 個變體），執行檢測，取得適應性標籤。
2. ESM-2+MLP：用目前所有資料訓練/更新代理模型。
3. BO 指標函數：提出下一批 K 序列（batch qLogEI，q> 1）或考慮 Thompson Sampling；
4. 濕實驗室：合成並測定 K 序列的適應性。
5. 回到步驟 2，實行 5–10 輪。

關鍵實際考量：可合成性限制（避免稀有密碼子）、多樣性懲罰以防 BO 崩潰到局部區域，以及 不確定性校準——GP 不確定性必須反映真實誤差，需定期重新校準。
ProteinMPNN 和 AlphaFold2 有什麼關係？
兩者都處理相同的蛋白質結構-序列關係，但方向相反：

AlphaFold2：序列 → 結構（結構預測）。給定氺基酸序列，透過 Evoformer+結構模組預測 3D 骨架坐標。

ProteinMPNN：結構 → 序列（逆折疊 / 生成目標骨架（RFdiffusion / FrameDiff）；（2）用 ProteinMPNN 設計能折疊成該結構的序列；（3）用 AlphaFold2 驗證各設計（pLDDT > 80 作為筋選）；（4）濕實驗室驗證頂尖候選。這個繁雜管線贏得了 2022 年蛋白質設計挑戰賽冠軍。
你的 wet lab 背景如何與這個 AI
我的濕實驗室背景（3 年以上）直接帶來三項優勢：

1. 檢測設計直覺：我能判斷哪種實驗讀出（DSF 的 Tm、kcat/KM、熱爭變性 ΔΔG）作為適應性代理最有資訊量，並知道如何減少測量雜訊——這對 BO 中 oracle 函數的質量至關重要。

2. 序列空間意識：我知道蛋白質哪些區域能容忍突變（loop 與活性位殘基酸的差異），並可將此編碼為獎勵函數的 軟約束或 GP 核的先驗知識。

3. 失效模式診斷：當 AI 設計的變體在實驗室失效，我能分辨是般因错誤折疊、聚集還是催化失活，並將此反饋為結構化負資料重新訓練代理模型。
